eazygadgetz.de setzt keine Cookies und verwendet keine Analyse-, Werbe- oder Social-Media-Tools. Schriftarten und Bilder werden von unserem eigenen Server geladen; es werden keine Inhalte von Drittanbietern nachgeladen. Ein Consent-Banner ist deshalb nicht erforderlich.

Diese Parameter enthalten keine personenbezogenen Daten; sie werden auf dieser Seite nicht gespeichert, sondern lediglich an den Link zu unserem Shop angehängt, damit wir erkennen, über welchen Kanal eine Bestellung zustande kam.
